ONE SHARED LEARNING PATH

🐍 Python Learning Lab

Python is for curious learners through Grade 10. Work through the ideas in order, practise each one, and keep coming back as your programs grow.

Start learning ↓

🧠 Programming logic first

Programming is problem solving. Before writing code, understand the goal, break it into steps, predict the result, test an example, and improve the solution when it does not work.

1. Understand the goal2. Break it into steps3. Predict the output4. Test and debug

Learn the path in order

1. Output and values

Use print(), text strings, numbers, and assignment with =.

name = 'Maya'
print('Hello,', name)

2. Decisions and repetition

Use if for choices and for/while loops for repeated work.

for number in range(1, 4):
    print(number)

3. Functions and strings

Package a solution in a function, return a result, and transform text with string methods.

def double(number):
    return number * 2
print(double(6))

4. Data and objects

Use lists and dictionaries to organise information, then classes to bundle data and behaviour.

student = {'name': 'Asha', 'score': 92}
print(student['score'])

5. Algorithms

Design step-by-step solutions using sorting, searching, comprehensions, and recursion. Think about correctness and efficiency.

numbers = [1, 2, 3, 4]
squares = [n * n for n in numbers]
print(squares)

There is no separate grade track here: learners can start at the first topic and move forward when they are ready.
