💉 How do vaccines train your body?

Vaccines help your body make memory cells so it can fight a germ faster if it shows up later.

The big idea

Vaccines trigger a first immune response and create memory cells, which can respond faster and stronger if the same germ returns.

How it works

🦠

Antigens

An antigen is the part of a germ your immune system recognizes as foreign.

🛡️

Antibodies

B-cells multiply and make antibodies that bind to the germ.

🧠

Memory

Memory cells give a faster, stronger response if the germ returns.

Quick stats

1germ per memory cell
1illness targeted per vaccine
0illnesses needed to build memory
2steps: first response, then memory

More about the human body

  • Smallpox has been eradicated, and polio, measles and rubella are considered eliminated in the U.S.
  • Some vaccines, called mRNA vaccines, give cells instructions to make the antigen.
  • A vaccine only protects against the illness it targets.

Words to know

Antibody
A tiny protein that sticks to a germ.
Vaccine
A shot or dose that trains your immune system.

🧪 Try it yourself

Think of a vaccine as a practice drill for a fire crew. They practice first so they are quick when the real fire shows up.
