⚖️ What makes a test fair?

In a fair test you change only one thing and keep everything else the same.

🎉 Great job!

The big idea

A fair test changes only one thing at a time.

How it works

☝️

One change

Change one factor at a time.

🟰

Same rest

Keep all other conditions the same.

🌱

Example

Plants need the same soil when testing fertilizer.

Quick stats

1thing changed
Allother conditions kept equal
Samesoil for each plant
Samestart for each car

More about nature

  • A push on one car gives it an unfair advantage.
  • Different soil makes a fertilizer test unfair.
  • The changing factor is called a variable.

Words to know

Variable
The one factor you change.
Fair test
A test that changes one thing only.

🧪 Try it yourself

Roll two toy cars down a ramp. Start them the same way each time. Change only the car.
