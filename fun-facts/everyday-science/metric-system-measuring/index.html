📐 Why do scientists use the metric system?

It lets everyone measure the same way, and it is decimal.

The big idea

The metric system is decimal, so converting is easy.

How it works

🌍

Shared

Everyone measures the same way.

🔟

Decimal

Each step is a factor of 10, 100 or 1,000.

📏

Units

Meter, liter and gram are base units.

Quick stats

1,000meters in a kilometer
100centimeters in a meter
1,000milliliters in a liter
1,000grams in a kilogram

More about nature

  • Degrees Celsius measure temperature.
  • Inches in a foot and feet in a mile need more memorizing.
  • Prefixes go up or down by powers of ten.

Words to know

Metric
A measuring system based on tens.
Prefix
A word start that changes a unit, like kilo.

🧪 Try it yourself

Measure your pencil in centimeters. How many millimeters long is it?
